This folder contains a minimal example for an iOS + watchOS companion flow.\n\nHigh level:\n- watchOS app records short audio (e.g., 3-6s), sends it to the iPhone via WatchConnectivity (transferFile or sendMessage with a file URL).\n- iOS app receives the file and forwards it to the Ella backend at POST /api/watch/audio with JSON { filename, data } where data is base64-encoded audio bytes.\n- For simple commands (start/stop/lock/open), the watch sends a small sendMessage to the iPhone, which issues a POST /api/watch/command.\n\nNotes:\n- This repository only contains sample Swift snippets; you'll need Xcode to build the iOS + watchOS targets.\n- Configure the iPhone app with the host URL (http://<YOUR_PC_IP>:3001) and WATCH_TOKEN if used.\n
